# **App Name**: MediScan AI

## Core Features:

- Document Upload: Upload medical reports in PDF, PNG, and JPG formats.
- AI Analysis: Send uploaded reports to the Gemini API for analysis and actionable insight using tool.
- Patient-Friendly Summary: Generate a simplified summary of the report for patients.
- Doctor-Style Summary: Generate a detailed, technical summary of the report for medical professionals.
- Lifestyle & Health Suggestions: Provide lifestyle and health recommendations based on the report findings.
- Interactive Q&A: Allow users to ask questions about their reports and receive AI-powered answers.

## Style Guidelines:

- Primary color: Deep teal (#008080) to evoke trust and medical expertise.
- Background color: Light teal (#E0F8F8) for a clean and professional feel.
- Accent color: Soft yellow (#F0E68C) for highlighting important information.
- Body font: 'Inter', a grotesque-style sans-serif, to ensure that all text, including the medical jargon, looks clean.
- Headline font: 'Space Grotesk', a sans-serif to add an additional layer of legibility. Should any code snippets need to be rendered, consider using 'Source Code Pro'.
- Use clear and recognizable medical icons.
- A clean, card-based layout for report sections.
